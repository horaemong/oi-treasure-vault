상태를 변경하기

훅 함수 useState함수는 두 개의 값이 들어간 배열로 이루어져있다. 첫 번째 값은 바뀐 값을 담고 있고, 두 번째 값은 변경할 값을 담는다. 두 번째 값이 바뀌면 해당 함수만 재실행하고, dom에서 바뀐 부분만 새로 가져온다. 이미지/첨부: 2025-05-25 22 34 53.png이미지/첨부: 2025-05-25 22 48 41.png

상태 올리기

필요한 곳(상위 컴포넌트)에서 값의 변화가 있는 곳(하위 컴포넌트)으로 전달.

하위 컴포넌트에서 상태변화가 일어나고, 상위 컴포넌트의 dom이 바껴야 할 경우 이 와 같이 하면 된다.
