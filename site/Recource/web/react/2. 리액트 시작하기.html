연결: web React

**프로젝트 시작하는 법

  1. npx create-react-app

    2. or npm create vite

  2. npm install -> 리액트 앱을 빌드하거나 실행할 때 필요한 것들을 다운 받아줌
  3. vite 이용했다면 npm run dev / 아니면 npm start
