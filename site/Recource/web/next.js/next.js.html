next.js의 시작

  1. nodejs lts버전 다운로드
  2. nextjs 프로젝트를 생성할 폴더를 만든다.
  3. 그 폴더에서 powershell을 열고 `` npx create-next-app@latest ``을 입력한다.
  4. 본인이 개발한 웹을 보고 싶으면 `` npm run dev ``를 터미널에 입력한다.

프로젝트 파일

[!done]- app 폴더 : 코드를 짜는 폴더

- api 폴더 : 서버 기능 만드는 곳
  • next.config.js : nextjs 설정 파일

  • package.json : 설치한 라이브러리 버전 기록용 파일
