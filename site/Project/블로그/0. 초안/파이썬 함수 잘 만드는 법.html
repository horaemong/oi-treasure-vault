파이썬 함수 쓰는 법

def 함수 이름(매개 변수 1, 매개 변수 2): 함수 기능 return 남기고 싶은 값

def 함수 이름(* 매개 변수 이름): 함수 기능 return 남기고 싶은 값

이런 식으로 쓰면 된다.

매개 변수는 함수에서 값을 받아오는 역할을 한다. 매개 변수 앞에 * 을 붙이면 여러개를 받아올 수 있다.

함수 잘 만드는 법

함수는 죽은 호랑이의 가죽 / 죽은 사람의 이름과 같은 것이다. 함수는 죽으면 본인의 기능을 남기는 것이다.

함수는 return을 이용해 변수에 값을 담거나, return을 안쓰고 오직 기능만 하고 사라진다.

return은 호랑이 가죽, return을 쓰지 않는 함수는 사람의 이름이다.

  1. return의 경우

아래의 함수는 특정 사이트에서 news의 정보를 끌어오는 기능을 하는 함수이다. 함수의 기능 구현을 이해할 필요 없다. 아래에 return 부분만 보자.

def news_api(request):  
    # 옵션 생성  
    options = webdriver.ChromeOptions()  
    # 창 숨기는 옵션 추가  
    options.add_argument("headless")  
    driver = webdriver.Chrome(options=options)  
    driver.get("https://coinness.com/")  
    time.sleep(2)  
    titles = driver.find_elements(By.CLASS_NAME, "BreakingNewsTitle-sc-glfxh-4")  
    contents = driver.find_elements(By.CLASS_NAME, "BreakingNewsContents-sc-glfxh-5")  
	
	
    news = [  
        {"titles": titles[0].text, "contents": contents[0].text, "id": 1},  
        {"titles": titles[1].text, "contents": contents[1].text, "id": 2},  
        {"titles": titles[2].text, "contents": contents[2].text, "id": 3},  
    ]  
  
    return news
news = news_api(request)

이 함수는 값을 남기기에 사용하기 위해서는 변수에 담아줘야 한다. 이렇게 선언하면 함수는 본인의 기능을 하고 news에 담긴 값을 남긴다. news라는 변수에 news 데이터가 담긴 것이다. 함수는 죽고 news라는 가죽을 남기고 간 것이다.

  1. return을 쓰지 않는 경우

아래의 함수가 파이썬 예제가 아니라서 미안하다. 전에 내가 만들었던 파이썬 프로젝트가 어디로 갔는지 모르겠다. 어쨌든 앱을 개발할때 쓰이는 flutter에서 쓴 함수이다. 갤러리에서 이미지를 가져오는 함수이다. 아래에 return이 있는지 보자.

Future<void> _pickImage() async {

    ImagePicker().pickImage(source: ImageSource.gallery).then((image) {

      if (image != null) {

        setState(() {

          file = image;

          imageList.insert(imageCount, image.path);

          imageCount += 1;

        });

        // print(imageList[imageCount - 1]!.path);

      }

    });

  }

이 함수는 보면 return을 쓰지 않은 함수이다. 이 함수는 기능만 하고 살아지는 것이다. 보통 전역변수 위치에 있는 공통적으로 쓰이는 값을 변경하는 경우 return을 안 쓰는 경우가 많다. 이 함수는 죽고 전역에 영향을 미치는 것이다. 유명한 사람은 많은 사람에게 영향을 줬기에 이름이 남은 것이다. return 없는 함수도 이와 같다. 이 함수는 역할을 다하고 죽으며 전역에 영향을 미치고 가는 것이다.

그럼 함수의 내용은? 함수에는 어떤 내용이 들어가야 할까?

  1. 똑같은 코드가 여러 번 들어가는 경우
  2. 코드의 가독성이 떨어질 때
  3. 하나의 함수의 내용은 한 가지만

글을 잘 쓰는 법과 굉장히 비슷하다고 생각한다.

  1. 같은 내용(함수)이 들어가면 글은 재미없다.
  2. 글의 과한 tmi(함수)가 들어가면 가독성이 떨어진다.
  3. 한 문장(함수)에는 한 가지의 내용(함수)만

어떤가 정말 비슷하지 않나? 코딩도 하나의 언어이다. 컴퓨터랑 대화하는 언어이다. 코딩을 잘 하는 방법은 우리가 언어를 잘하기 위해 하는 노력과 굉장히 비슷하다.
