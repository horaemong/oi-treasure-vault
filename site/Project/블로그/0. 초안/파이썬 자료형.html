연결: 블로그 블로그 초안

이 글에는 세세한 활용법을 적지 않을 것이다. 이 글은 자료형을 공부하는 방법과 어디까지 공부해야하는지에 대해 이야기 할 것이다.

  1. 어떻게 공부해야 하나?

    2. 파이썬은 처음 시작하는 사람은 숫자형, 문자열, 리스트, 딕셔너리, 불 자료형 정도만 외우고 시작하면 된다. '파이썬은 자료형은 그렇게 신경 쓸 필요 없지 않나요?' 라는 질문을 할 수도 있다. 파이썬으로 개발을 하다 보면 자료형 때문에 많은 오류를 겪을 수 있을 것이다. ex) print (다른 자료형 + ' : 테스트') -> TypeError 발생 해결 : print(str(다른 자료형) + ' : 테스트') 위에가 자주 생기는 오류 중 하나이다. print라는 함수 안에는 무조건 문자열 자료형이 들어가야 하지만 다른 것이 들어가니 함수가 작동하는 과정에서 오류가 생기는 것이다. 이미지/첨부: lock-6314371_640.png 자물쇠에 맞지 않는 열쇠를 사용하는 것과 같은 상황이 생기기에 자료형에 대한 이해가 필요하다.

  2. 파이썬의 자료형
  3. 숫자형

    4. 말그대로 숫자를 나타낸다. a = 1 처럼 사용한다. 특정 자료형은 숫자형으로 바꾸고 싶으면 int(변수)로 하면 숫자형으로 바뀐다. 데이터베이스를 다루다보면 날짜형 자료형이나, 문자형 자료형을 숫자형으로 바꾸고 싶을 때가 있는데, 이 때 사용하면 된다.

  4. 문자형

    5. 문자를 나타내는 자료형이다. a='파이썬은 좋다' 와 같이 사용한다. print문을 정말 많이 사용하게될 텐데 print 문은 함수이다. 함수 안에는 그 함수가 요구하는 자료형만 줘야하기에 신경써야한다. print문 안에 다른 자료형을 쓰고 싶다면, str(변수)처럼 감싸주면 된다.

  5. 리스트

    6. 리스트 자료형은 여러 개의 자료를 하나의 변수에 담고 싶을 때 사용한다. a=[1,2,3]처럼 사용한다. 리스트 안에는 어떤 자료형도 넣을 수 있다. a=[1,2,[1,2,3]]처럼 리스트안에 리스트를 넣어 줄 수 있다.

  6. 딕셔너리

    7. a={'key':'value'}처럼 사용한다. 특정 key에 대한 value를 찾아 올 수 있는 자료형이다. a['key']로 입력하면 value 값을 가져올 수 있는 자료형이다. 딕셔너리의 사용처가 궁금할 것이다. 관계성을 표현한 정보를 표현할때 많이 쓴다. 리스트 자료형과 연계해 아래와 같이 사용할 수 있다. people = [{'name' : '돌쇠', 'phone':01098765432},{'name' : '복순이', 'phone':01023456789}]

  7. 변수

    8. 변수는 데이터를 담을 수 있는 공간이다. 위에서 'a='으로 사용했을 것이다. a라는 저장소에 데이터를 저장하겠다는 뜻으로 사용할 수 있다. 어떤 데이터든 저장하고 싶으면 변수를 만들면 된다. a 자리에는 본인이 원하는 이름 아무거나 넣으면 된다.
