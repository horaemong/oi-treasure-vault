연결: 블로그 블로그 초안

어떤 프로그래밍 언어든 반복문과 조건문이 정말 중요하다. 프로그래밍 언어의 꽃과 같은 것이다. 그정도로 중요하다. 하지만 걱정마라. 그렇게 어려운 개념이 아니다.

파이썬은 다른 언어와 다르게 중괄호를 거의 안 쓰는 언어이다. 딕셔너리, 오브젝트 자료형 제외하면 쓰는 곳이 없다. 조건문은 아래와 같이 쓴다. if 조건 내용: 조건 내용과 맞으면 작동 else if 조건 내용: if 조건과 다르고, else if의 조건과 일치하면 작동 else: 위에 조건과 일치하는 것이 없다면 작동

조건문은 위와 같이 간단하다. 그럼 조건문은 어떻게 공부해야 할까? 예를 들어보자.

네이버의 로그인 시스템을 예로 들겠다. 이미지/첨부: 2025-06-05 15 23 56.png 조건문을 공부할 때는 어떤 앱이든 웹이든 어떤 조건에서 작동할지 고민해보면 빠르게 실력이 늘 것이다. 이해도 쉬울 것이다. 작동 순서를 적어보자.

  1. 아이디와 비밀번호를 입력한다.
  2. 로그인 버튼을 누른다.
  3. 아이디와 비밀번호가 맞는지 확인하다.(조건)
  4. 아이디와 비밀번호가 맞으면 로그인한다.
  5. 이때 로그인 상태 유지의 체크 상태를 확인한다.
  6. 체크 상태면 다음에도 자동 로그인 되게 한다.
  7. 아니면
  8. 아이디와 비밀번호가 틀리면 다시 입력하게한다.

이미지/첨부: 2025-06-05 15 24 14.png

로그인 상태인지 아닌지 확인한다. (조건)

  1. 로그인 상태가 아니면 1번 이미지를 화면에 띄운다.
  2. 로그인 상태가 맞다면 2번 이미지를 화면에 띄운다.

위와 같이 조건문은 여러 앱 또는 웹들의 어떤 조건일때 작동하는지 분석하다 보면 자연스럽게 실력이 늘 것이다.
