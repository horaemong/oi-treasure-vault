Decisions

  • Use _handoff as the shared communication folder between Antigravity and Codex.
  • Antigravity writes planning and research output to _handoff/antigravity-to-codex.md.
  • Codex writes research or planning requests to _handoff/codex-to-antigravity.md.
  • context.md stores stable project context.
  • decisions.md stores user-approved decisions and should not be overridden unless the user changes them.
  • The user is the final source of truth.
