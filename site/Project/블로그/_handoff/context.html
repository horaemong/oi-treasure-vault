Project Context

This folder is the shared handoff space between Antigravity, Codex, and the user.

Antigravity is used for planning, research, ideation, critique, and broad strategy.

Codex is used for local file editing, implementation, verification, reusable workflow creation, and project-state maintenance.

The user is the final decision-maker.
