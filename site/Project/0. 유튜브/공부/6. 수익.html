연결: 유튜브 유튜브 공부

방법

  1. 영상 광고
  2. 유료 후원
  3. 유료 광고
  4. 부가 수익(파트너스 링크)
  5. 사업 연계(강의 팔의, 사업 마케팅) <- 내가 유튜브를 시작하려는 가장 큰 이유

뻥조회수는 수익에 관계 없음

쇼츠 RPM은 영상길이와 같은 것에 영향을 잘 받지 않음. 그나마 국가 차이가 있음. 조회수 1당 200원

롱폼은 8분 이상부터 유의미한 차이가 나오니, 최소 8분. 8분 이상부터는 길이를 신경쓰지 않아도 됨. 영상의 재미를 챙길 것.

끝광고를 보게하기위해 아웃트로를 없애고, 갑자기 뚝 끊기게 편집을 하는 경우가 많아지고 있음

노란 딱지가 너무 많으면 저품질 채널로 영향이 있을 수 있으니, 최대한 피할 것.

멤버쉽은 꾸준히 혜택이 있어야 하는데, 그건 어려우니 딱 부가수입 정도의 위치에서 가볍게 운영하는게 좋음

유료 광고는 일반화 불가

음원 협업

유튜브만큼 강력한 홍보 시스템이 없음

세금

종소세는 누구나 내야함. -> 연장선 : 건보료, 국민 연금

부가가치세는 본인의 상황에 따라 달라지니 잘알아볼 것

원천세는 누군가에게 돈을 줄 떄. 구독자 이벤트, 편집자 월급 등등

사업자 등록

총 수익 1천만원 넘어가는 시점에는 사업자 등록이 필요해지는 시점

업종 코드 94 : 1인 미디어, 면세 사업자. 92 : 미디어 콘텐츠 창작업. 다수, 과세 사업자. 영세율이라는 혜택을 받어 부가세 금액이 없음. 대신 신고의 의무가 있고, 외화만 영세율이 포함. 사업에 필요한 물품을 샀을 때 부가세를 돌려받을 수 있음.

일반 과세자로 가는게 이득인 경우가 많음

원천세 사업 소득 : 편집자 월급같은거, 정식 계약하면 근로소득으로 들억마

기타 소득 : 일시적인 소득, 22%

공모전은 4.4 일시적인 용역 제공 8.8

초입에는 괜찮지만 복잡해지면 세무사를 쓰자.
