연결: 유튜브 유튜브 공부

인트로

지루한 연출은 전부 빼기

롱폼 인트로 구분이 안되게 자연스럽게 본편으로 넘어가는 방법도 있음

비교적 불필요한 것을 덜어낼 필요가 있음

예를 들어 24시간 oo 챌린지를 진행할 때 시작부터 보여주는게 아닌 어느 정도 진행된 상태에서 영상을 시작하는 방식

인트로에 모든 것을 전달하려할 필요 없음. 영상을 진행하며 자연스럽게 설명하고 싶은 내용(배경지식 등등)을 섞어 넣으면 됨

하이라이트 미리보기식 인트로에서 나레이션으로 설명하며 시작하는 방식으로 변화하고 있음

숏폼 롱폼처럼 인트로를 짜면 안됨. 썸네일과 제목을 보고 들어온 롱폼과 다르게 불특정 다수에게 보이기 때문임.

먼저 무엇을 할지 말하고 그걸 하는 이유를 말해라.

결과를 먼저 말하고 원인을 이야기하며 숏츠에 내용을 채워가는 거임

영상

결론은 마무리 단계에 나와야 함.

결론을 너무 빠르게 말하면 거기서 영상을 끔

만약 결론이 빠르게 나와야 한다면 결론이 나오고 새로운 궁금증을 던져야함

쓸데없는 내용은 쳐내야함. 최대한 핵심만 보여주기

차라리 부족한 느낌이 드는게 훨씬 좋음

스토리를 그리고로만 연결되어 있으면 지루함. 그러나와 그래서의 구조로 연결할 것

나레이션을 활용하기. 영상의 윤활제로 사용하면 좋음

몰입이 되는 영상을 만들기. 같이 이입해서 3인칭이 아닌 1인칭으로 볼 수 있는 영상이 되게 만들기

그러기 위해 가상의 인물과 1대1로 소통하고 있다는 상상하며 그렇게 만들기. 혹은 공동체 의식을 건드리기. '우리'와 같은 키워드를 써 같이 무언가를 한다고 느끼게 만들기

성공사례 참고, 즉 벤치마킹을 잘 하기

시각적 효과를 이용해 지루하지 않게 만들어야함.

근데 쫀득이 같이 라디오 느낌을 추구하면 시각 효과를 최소화 하는 경우가 있음. 대신 오디오가 비지 않음. 오디오가 지루하지 않게함.

시청자가 어떤식으로 영상을 시청하냐에 따라 선택해야함. 단 어떤 선택이든 집중한 부분은 지루하면 안됨.

편집

숏츠에서 자막은 중간이나 위가 좋음. 롱폼에서는 오른쪽과 너무 아래를 피하면 좋음

참여 유도

구독 좋아요를 눌러달라고 하는 행위.

구독이나 좋아요로 참여하면 실제로 영향이 있는 것들이 좋음. 실제로 참여한다는 느낌이 들게 하는 거.

참여 유도를 잘 쓰면 성장이 매우매우 유리
