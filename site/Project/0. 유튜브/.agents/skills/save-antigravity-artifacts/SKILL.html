Save Antigravity Artifacts Skill

이 스킬은 안티그래비티(Antigravity)가 생성한 주요 연구, 기획, 데이터 분석 리포트 등의 아티팩트 파일을 임시 격리 디렉토리에만 보관하지 않고, 사용자의 실제 워크스페이스에 즉시 보존하여 영구적으로 아카이빙하고 코덱스(Codex)와도 매끄럽게 문맥을 공유하기 위해 사용됩니다.

1. 실행 조건 및 흐름

  1. **아티팩트의 복제**:
  • 안티그래비티가 분석 및 기획 본문 파일(예: *_research_*.md, *_strategy_*.md 등)을 아티팩트 저장소(C:\Users\user\.gemini\antigravity\brain\<conversation-id>/)에 생성할 때, 동시에 또는 직후에 로컬 프로젝트 루트 아래에 antigravity/ 디렉토리를 생성합니다.
  • 해당 보고서 파일의 복사본을 [ProjectRoot]/antigravity/[filename].md 경로에 새로 작성합니다.
  1. **참조 경로의 일괄 업데이트**:
  • 워크스페이스 내의 다른 협업 문서(특히 _handoff/context.md, _handoff/antigravity-to-codex.md, README.md, walkthrough.md 등)에서 해당 보고서를 참조하는 파일 하이퍼링크 file:///... 경로를 임시 아티팩트 경로에서 신규 antigravity/ 프로젝트 하위 경로로 일괄 교체해 주어야 합니다.

2. 주의사항

  • 로컬 프로젝트 하위에 생성할 때는 아티팩트 메타데이터(ArtifactMetadata) 인자를 write_to_file 도구 호출 시 제공하지 않아야 오류가 발생하지 않습니다.
  • 윈도우 환경에서는 마크다운 링크 파싱 오류를 방지하기 위해 파일 경로 작성 시 역슬래시(\) 대신 포워드 슬래시(/)를 표준으로 사용합니다.
