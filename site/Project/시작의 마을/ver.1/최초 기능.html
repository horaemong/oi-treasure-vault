연결: 시작의 마을

최초 기능

일지 루틴 체크리스트

루틴별 경험치 제공

마이페이지 스탯창

쓸 기술 확장성을 고려한 react + django

쓰는 이유 react를 통한 인터랙티브 웹앱 개발 django를 통한 백엔드 관리. django가 db 관리하기 편함. 로직 짜는건 js보다는 python으로 내가 훨씬 더 잘함

이것을 최소 기능으로 잡은 이유

일지를 깔끔하게 쓸 수 있는 기능을 처음부터 쓰면 좋겠지만 이것자체를 개발하는데 오래 걸릴거 같음. 어떤 사용자가 써도 쓰기 쉽게 템플릿을 제공하려고 했는데, 이것이 기초 템플릿이 될거라고 생각함. 가장 간단한 형태. 일단 글을 올려야 주간, 월간, 년간으로 관리 할 수 있게 됨.

지금 블로그에 일지 쓰고 있는데 이 과정을 좀 더 간단하게 만들고 싶음
