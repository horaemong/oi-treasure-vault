C 수집

O 추출

  1. 할 일 뽑아내기

    2. 내가 수집 해 놓은 것 중 어떻게든 할 일 뽑아내기

  2. 노트 쪼개기

    3. 한 노트에는 하나의 정보만 넣기(나중에 찾기 쉽게 하기 위함) ex) 독후감과 독후감에서 얻은 다른 내용으로 노트 쪼개기

  3. 제목 짓기

    4. 나중에 노트를 찾기 쉽게 일종의 할 줄 요약임

E 표현

    2. 일단 옵시디언을 뒤지고 없는 새로운 정보가 인터넷에서 찾음

  2. 프로젝트 종료 습관

    3. 끝난 후 다시 정리해서 끝내기
