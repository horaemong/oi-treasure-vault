확률변수 암기용 공식 모음

1. 공통 공식

이산확률변수

E[X] = sum_x x p_X(x)
E[g(X)] = sum_x g(x)p_X(x)
var(X) = E[(X - E[X])^2]
var(X) = E[X^2] - (E[X])^2
std(X) = sqrt(var(X))

연속확률변수

P(a <= X <= b) = integral_a^b f_X(x) dx
E[X] = integral_{-infinity}^{infinity} x f_X(x) dx
E[g(X)] = integral_{-infinity}^{infinity} g(x)f_X(x) dx
var(X) = E[X^2] - (E[X])^2

선형변환

Y = aX + b
E[Y] = aE[X] + b
var(Y) = a^2 var(X)

기대값의 선형성

E[X + Y] = E[X] + E[Y]
E[aX + bY + c] = aE[X] + bE[Y] + c

독립 확률변수

X, Y independent
p_X,Y(x,y) = p_X(x)p_Y(y)
E[XY] = E[X]E[Y]
var(X + Y) = var(X) + var(Y)

2. 조건부 공식

조건부확률

P(A | B) = P(A intersection B) / P(B)

조건부 PMF

p_{X|Y}(x|y) = p_X,Y(x,y) / p_Y(y)
p_X,Y(x,y) = p_Y(y)p_{X|Y}(x|y)

전체 기대값 정리

E[X] = sum_y P(Y = y)E[X | Y = y]

조건부 기대값

E[X | Y = y] = sum_x x p_{X|Y}(x|y)
E[g(X) | Y = y] = sum_x g(x)p_{X|Y}(x|y)

3. 결합 PMF

p_X,Y(x,y) = P(X = x, Y = y)
p_X(x) = sum_y p_X,Y(x,y)
p_Y(y) = sum_x p_X,Y(x,y)
E[g(X,Y)] = sum_x sum_y g(x,y)p_X,Y(x,y)

특히:

E[X] = sum_x sum_y x p_X,Y(x,y)
E[Y] = sum_x sum_y y p_X,Y(x,y)
E[XY] = sum_x sum_y xy p_X,Y(x,y)

4. CDF 공식

정의

F_X(x) = P(X <= x)

이산형

F_X(x) = sum_{k <= x} p_X(k)
P(X = k) = F_X(k) - F_X(k-1)

연속형

F_X(x) = integral_{-infinity}^{x} f_X(t) dt
f_X(x) = dF_X(x) / dx

CDF 성질

F_X(x) is non-decreasing
lim_{x -> -infinity} F_X(x) = 0
lim_{x -> infinity} F_X(x) = 1

최솟값

Z = min(X1, X2)
F_Z(z) = P(Z <= z)
       = 1 - P(Z > z)

Z > z <=> X1 > z and X2 > z

If X1, X2 independent:
F_Z(z) = 1 - P(X1 > z)P(X2 > z)

최댓값

Z = max(X1, X2)
F_Z(z) = P(Z <= z)
       = P(X1 <= z, X2 <= z)

If X1, X2 independent:
F_Z(z) = F_X1(z)F_X2(z)

5. 베르누이분포

X ~ Bernoulli(p)
P(X = 1) = p
P(X = 0) = 1-p
E[X] = p
var(X) = p(1-p)

6. 이항분포

X ~ Binomial(n,p)
P(X = k) = C(n,k)p^k(1-p)^(n-k),  k = 0,1,...,n
E[X] = np
var(X) = np(1-p)

7. 기하분포

X ~ Geometric(p)
P(X = k) = (1-p)^(k-1)p,  k = 1,2,3,...
E[X] = 1/p
var(X) = (1-p)/p^2

8. 포아송분포

X ~ Poisson(lambda)
P(X = k) = e^(-lambda)lambda^k / k!,  k = 0,1,2,...
E[X] = lambda
var(X) = lambda

9. 음이항분포

X = k번째 성공이 나올 때까지 필요한 시행 횟수
P(X = n) = C(n-1,k-1)p^k(1-p)^(n-k),  n = k,k+1,...

10. 이산 균등분포

X ~ Uniform{a,a+1,...,b}
P(X = k) = 1/(b-a+1),  k = a,...,b
E[X] = (a+b)/2
var(X) = ((b-a+1)^2 - 1)/12

11. 연속 균등분포

X ~ Uniform(a,b)
f_X(x) = 1/(b-a),  a <= x <= b
E[X] = (a+b)/2
var(X) = (b-a)^2/12
P(c <= X <= d) = (d-c)/(b-a)

특히:

X ~ Uniform(0,1)
f_X(x) = 1,  0 <= x <= 1
P(X > z) = 1-z,  0 <= z <= 1
P(X <= z) = z,  0 <= z <= 1

12. 지수분포

X ~ Exponential(lambda)
f_X(x) = lambda e^(-lambda x),  x >= 0
E[X] = 1/lambda
var(X) = 1/lambda^2
P(X > a) = e^(-lambda a)
P(X <= a) = 1 - e^(-lambda a)

무기억성:

P(X > s+t | X > t) = P(X > s)

13. 정규분포

X ~ Normal(mu, sigma^2)
E[X] = mu
var(X) = sigma^2

표준화:

Z = (X - mu) / sigma
Z ~ Normal(0,1)

표준정규분포:

Phi(z) = P(Z <= z)

확률 변환:

P(X <= a) = Phi((a - mu)/sigma)
P(X >= a) = 1 - Phi((a - mu)/sigma)
P(a <= X <= b) = Phi((b - mu)/sigma) - Phi((a - mu)/sigma)

선형변환:

If X ~ Normal(mu, sigma^2),
Y = aX + b
Y ~ Normal(a mu + b, a^2 sigma^2)

14. 두 번 연속 성공 기대 횟수

p = success probability
q = 1-p

E0 = 직전 시행이 성공이 아닌 상태에서 남은 기대 횟수
E1 = 직전 시행이 성공인 상태에서 남은 기대 횟수

E0 = p(1 + E1) + q(1 + E0)
E1 = p(1 + 0) + q(1 + E0)

E0 = (1+p)/p^2

15. 자주 쓰는 여사건

P(X >= 1) = 1 - P(X = 0)
P(X > a) = 1 - P(X <= a)
P(X <= a) = 1 - P(X > a)

연속형:

P(X < a) = P(X <= a)
P(X > a) = P(X >= a)
P(X = a) = 0

16. 한눈에 보는 평균과 분산

Bernoulli(p):              E[X] = p,          var(X) = p(1-p)
Binomial(n,p):             E[X] = np,         var(X) = np(1-p)
Geometric(p):              E[X] = 1/p,        var(X) = (1-p)/p^2
Poisson(lambda):           E[X] = lambda,     var(X) = lambda
Discrete Uniform(a,...,b): E[X] = (a+b)/2,    var(X) = ((b-a+1)^2-1)/12
Continuous Uniform(a,b):   E[X] = (a+b)/2,    var(X) = (b-a)^2/12
Exponential(lambda):       E[X] = 1/lambda,   var(X) = 1/lambda^2
Normal(mu,sigma^2):        E[X] = mu,         var(X) = sigma^2
