연결: 대학교 마케팅

마케팅 목표

내 상품의 설득력 만들기, 내 상품을 매력적으로 느낄 가능성이 많은 사람의 유동성을 만들기 --> 내 상품을 구매하기 만들기

  1. 설득력 만들기 : 개요와 마케팅 목표 -> 방법 : 랜딩페이지와 sns 마케팅(이런 방향(배경)으로 설득력을 만들 것이다. 내 상품은 논리적 혹은 감정적 설득이 필요한 상품이기에 이런 방향을 선택했다는 것을 어필)
  2. 유동성 만들기 : sns 마케팅

랜딩 페이지 해설

이건 기획서의 흐름대로 나아가면 됨.

ppt 구조

  1. 개요와 마케팅 목표(랜딩 페이지와 sns매체에서 선택할 단어와 컨셉의 본질)
  2. 분석이 이러이러하다 → 랜딩 페이지에는 이렇게 녹였다. (랜딩 페이지 해설)
  3. 유튜브, 뉴스레터, x에 어떤 내용의 글을 올릴건지(sns 마케팅)

3번은 랜딩 페이지의 순서를 따라서 해설하며 sns 매체를 이야기하는 순서에 자연스럽게 진행하면 될 듯

마케팅적으로 해설하면 ppt는 충분히 좋게 나올 듯
