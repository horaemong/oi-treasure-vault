Employee.java 핵심 압축 정리

이 정리는 Employee.java에서 시험에 그대로 나올 가능성이 높은 부분 중, 부모 추상 클래스와 main의 파일 읽기/쓰기 부분만 남긴 것이다.

자식 클래스 작성은 제외하고, 시험장에서 코드 흐름을 잃지 않기 위한 순서 중심으로 정리한다.

1. import

파일 읽기/쓰기와 리스트/정렬을 위해 필요하다.

import java.io.*;
import java.util.*;

java.io.*는 파일 입출력용이다.

BufferedReader
FileReader
PrintWriter
FileWriter
FileNotFoundException
IOException

java.util.*은 리스트와 정렬용이다.

List
ArrayList
Collections
Comparable

2. 부모 추상 클래스

부모 추상 클래스는 공통 필드, 공통 생성자, 자식이 반드시 구현해야 하는 메서드, 정렬 기준을 가진다.

abstract class BaseEmployee implements Comparable<BaseEmployee> {
    protected String name;
    protected String typeCode;

    public BaseEmployee(String name, String typeCode) {
        this.name = name;
        this.typeCode = typeCode;
    }

    public abstract double getYearlySalary();
    public abstract String getEmployeeType();
    public abstract String toCsvRow();

    public String getName() {
        return name;
    }

    @Override
    public int compareTo(BaseEmployee other) {
        return Double.compare(other.getYearlySalary(), this.getYearlySalary());
    }
}

부모 추상 클래스에서 중요한 부분은 네 개다.

abstract class BaseEmployee

직접 객체를 만들 수 없는 부모 클래스라는 뜻이다.

implements Comparable<BaseEmployee>

Collections.sort(employees);로 정렬할 수 있게 한다.

public abstract double getYearlySalary();
public abstract String toCsvRow();

자식 클래스가 반드시 구현해야 하는 메서드다.

return Double.compare(other.getYearlySalary(), this.getYearlySalary());

연봉이 높은 순서대로 정렬한다. 즉 내림차순이다.

5. 명령줄 인자 확인

프로그램을 실행할 때 CSV 파일 이름을 받는 부분이다.

if (args.length != 1) {
    System.out.println("USAGE: <employees.csv> should be provided as a command line argument.");
    return;
}

String inputFileName = args[0];

실행 예시:

java Employee employees.csv

이때 args[0]에는 "employees.csv"가 들어간다.

String inputFileName = args[0];

만약 파일 이름 없이 실행하면 args.length가 0이므로 종료한다.

if (args.length != 1) {
    return;
}

6. 리스트 생성

파일에서 읽은 객체들을 저장할 리스트를 만든다.

List<BaseEmployee> employees = new ArrayList<>();

중요한 점은 자식 타입이 아니라 부모 타입으로 리스트를 만든다는 것이다.

employees.add(new FullTimeEmployee(name, monthlySalary));
employees.add(new HourlyEmployee(name, hours, rate));

서로 다른 자식 객체를 같은 리스트에 넣을 수 있다.

7. 파일 읽기 기본 구조

파일 읽기는 이 구조를 거의 그대로 외우면 된다.

try (BufferedReader br = new BufferedReader(new FileReader(inputFileName))) {
    String line;

    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (FileNotFoundException e) {
    System.out.println(inputFileName + " (The system cannot find the file specified)");
    return;
} catch (IOException e) {
    return;
}

핵심은 이 부분이다.

BufferedReader br = new BufferedReader(new FileReader(inputFileName))

inputFileName이라는 파일을 읽을 준비를 한다.

while ((line = br.readLine()) != null)

파일을 한 줄씩 읽는다. 더 이상 읽을 줄이 없으면 null이 되어 반복문이 끝난다.

8. 헤더 건너뛰기

CSV 첫 줄은 보통 제목 줄이다.

Type,Name,NumberOfHours,HourlyRate,MonthlySalary
F,Kim,,,3000
H,Lee,120,10,

첫 줄을 버리려면 while 전에 한 번 읽는다.

br.readLine();

파일 읽기 구조 안에서는 이렇게 들어간다.

try (BufferedReader br = new BufferedReader(new FileReader(inputFileName))) {
    String line;
    br.readLine();

    while ((line = br.readLine()) != null) {

    }
}

9. 빈 줄 건너뛰기

CSV 중간에 빈 줄이 있으면 처리하지 않고 넘어간다.

if (line.trim().isEmpty()) continue;

trim()은 앞뒤 공백을 제거한다.

"   ".trim().isEmpty()

위 코드는 true가 된다.

10. CSV 나누기

한 줄을 쉼표 기준으로 나눈다.

String[] data = line.split(",", -1);

Employee.java에서는 CSV가 이렇게 생겼다.

Type,Name,NumberOfHours,HourlyRate,MonthlySalary
F,Kim,,,3000
H,Lee,120,10,

인덱스는 이렇게 대응된다.

data[0] = Type
data[1] = Name
data[2] = NumberOfHours
data[3] = HourlyRate
data[4] = MonthlySalary

-1을 넣는 이유는 마지막 빈 칸도 살리기 위해서다.

String[] data = line.split(",", -1);

예를 들어 아래 줄에서 마지막 칸은 비어 있다.

H,Lee,120,10,

split(",", -1)을 쓰면 마지막 빈 칸까지 배열에 남는다.

11. 잘못된 줄 건너뛰기

필요한 칸 수보다 적으면 처리하지 않는다.

if (data.length < 5) continue;

Employee.java는 총 5칸이 필요하므로 5를 기준으로 검사한다.

문제에서 CSV 칸이 4개라면 이렇게 바꾼다.

if (data.length < 4) continue;

String type = data[0].trim();
String name = data[1].trim();

type은 어떤 자식 객체를 만들지 결정하는 값이다.

if (type.equals("F")) {

} else if (type.equals("H")) {

}

13. 숫자 변환

CSV에서 읽은 값은 전부 문자열이다.

String s = data[4].trim();

계산하려면 double로 바꿔야 한다.

double monthlySalary = Double.parseDouble(data[4].trim());

빈 칸이면 0으로 처리하는 방식:

double monthlySalary = data[4].trim().isEmpty()
        ? 0
        : Double.parseDouble(data[4].trim());

이 코드는 아래 뜻이다.

data[4]가 비어 있으면 0
비어 있지 않으면 double로 변환

시험에서 이름이 바뀌면 이 구조만 유지한다.

15. 파일 읽기 전체

시험에서 파일 읽기 부분은 아래 블록을 기준으로 외운다.

try (BufferedReader br = new BufferedReader(new FileReader(inputFileName))) {
    String line;
    br.readLine();

    while ((line = br.readLine()) != null) {
        if (line.trim().isEmpty()) continue;

        String[] data = line.split(",", -1);
        if (data.length < 5) continue;

        String type = data[0].trim();
        String name = data[1].trim();

        try {
            if (type.equals("F")) {
                double monthlySalary = data[4].trim().isEmpty()
                        ? 0
                        : Double.parseDouble(data[4].trim());

                employees.add(new FullTimeEmployee(name, monthlySalary));
            } else if (type.equals("H")) {
                double hours = data[2].trim().isEmpty()
                        ? 0
                        : Double.parseDouble(data[2].trim());

                double rate = data[3].trim().isEmpty()
                        ? 0
                        : Double.parseDouble(data[3].trim());

                employees.add(new HourlyEmployee(name, hours, rate));
            }
        } catch (NumberFormatException e) {
            // 데이터 형식 오류 시 해당 행 건너뜀
        }
    }
} catch (FileNotFoundException e) {
    System.out.println(inputFileName + " (The system cannot find the file specified)");
    return;
} catch (IOException e) {
    return;
}

17. 파일 쓰기 기본 구조

19. main 완성본

자식 클래스는 이미 작성되어 있다고 보고, main만 보면 아래와 같다.

public class Employee {
    public static void main(String[] args) {
        if (args.length != 1) {
            System.out.println("USAGE: <employees.csv> should be provided as a command line argument.");
            return;
        }

        String inputFileName = args[0];
        List<BaseEmployee> employees = new ArrayList<>();

        try (BufferedReader br = new BufferedReader(new FileReader(inputFileName))) {
            String line;
            br.readLine();

            while ((line = br.readLine()) != null) {
                if (line.trim().isEmpty()) continue;

                String[] data = line.split(",", -1);
                if (data.length < 5) continue;

                String type = data[0].trim();
                String name = data[1].trim();

                try {
                    if (type.equals("F")) {
                        double monthlySalary = data[4].trim().isEmpty()
                                ? 0
                                : Double.parseDouble(data[4].trim());
                        employees.add(new FullTimeEmployee(name, monthlySalary));
                    } else if (type.equals("H")) {
                        double hours = data[2].trim().isEmpty()
                                ? 0
                                : Double.parseDouble(data[2].trim());
                        double rate = data[3].trim().isEmpty()
                                ? 0
                                : Double.parseDouble(data[3].trim());
                        employees.add(new HourlyEmployee(name, hours, rate));
                    }
                } catch (NumberFormatException e) {
                    // 데이터 형식 오류 시 해당 행 건너뜀
                }
            }
        } catch (FileNotFoundException e) {
            System.out.println(inputFileName + " (The system cannot find the file specified)");
            return;
        } catch (IOException e) {
            return;
        }

        Collections.sort(employees);

        try (PrintWriter pw = new PrintWriter(new FileWriter("sorted_employees.csv"))) {
            pw.println("Type,Name,NumberOfHours,HourlyRate,MonthlySalary");

            for (BaseEmployee emp : employees) {
                pw.println(emp.toCsvRow());
            }
        } catch (IOException e) {
        }
    }
}
