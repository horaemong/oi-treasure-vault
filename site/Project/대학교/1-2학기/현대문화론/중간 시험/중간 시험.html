1. 근대 과학 혁명과 철학 (데카르트, 스피노자)

| 주제 | 주요 내용 | 출처 | | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | | **근대 기계론과 생각하는 주체** | 데카르트 | | | **서양의 근대 - 17세기** | 신 중심의 세계에서 인간 중심의 세계로 전환. 과학 혁명 발생. | | | **데카르트의 핵심 사상** | "나는 생각한다, 고로 존재한다". '나'는 생각하는 것(주체). | | | **데카르트의 과학관** | 물리학에서 기하학이나 수학에서 추상한 원리들 이외의 어떤 것도 허용하거나 희망하지 않는다. 그 원리들로 모든 자연 현상을 설명하고 확실한 증명들을 제시할 수 있기 때문이다. | | | **갈릴레오 비판 (데카르트)** | 갈릴레오가 수학적 근거를 통해 자연학적 문제를 검토한 점은 탁월하지만, 계속 지엽적인 문제로 빠져들고 자연의 일차적 원인을 고려하지 않고 특수한 결과의 이유만을 찾으려 했다. 데카르트는 '보편수리학(mathesis universalis)'을 강조한다. | | | **갈릴레오의 과학관** | 우주라는 거대한 책은 수학의 언어로 씌어져 있으며, 이 문자를 모르면 어두운 미로를 방황할 수밖에 없다. | | | **갈릴레오의 상대성 이론** | 물체가 '빨리 움직인다'거나 '정지해 있다'는 것은 상대적일 수 있다. (Galilean Invariance, Galiean Transformation) . | | | **데카르트의 자연학적 세계** | 연장을 통해 인식되는 것은 전 우주에 있어서 하나로 동일하게 존재하며 , 물질의 다양함이나 형상들의 차이는 모두 운동에 의존한다. | | | **데카르트의 운동 개념** | 일상적 의미의 운동은 물체가 한 장소에서 다른 장소로 이동하는 작용이며, 고유한 의미의 운동은 자신과 닿아 있고 정지해 있는 것으로 간주되는 물체와 인접함으로부터 다른 물체들과의 인접함으로의 이동이다. | | | **운동의 원인 (데카르트)** | 보편적이고 근원적인 원인(causa generalis)과 특수한 원인(causa particularis) 두 가지가 있다. 물체들에 일어나는 변화의 특수한 원인들은 충돌 법칙(제3법칙)에 담겨 있다. | | | **기계론의 의미** | 세계는 톱니바퀴로 가득 찬 기계와 같으며 , 모든 변화는 입자들의 충돌에 의해 발생한다. 동물은 기계이며, 동물의 비명은 기계적 반응으로 진정한 철학자라면 동물을 발로 찰 수 있어야 한다고 주장된다. | | | **인간과 기계** | 인간의 신체는 기계이다. 데카르트의 해결책은 인간 신체를 배(기계), 정신을 사공(마징가 Z 모델)으로 보는 것이다. '나'를 만드는 것은 '정신'이다. | | | **스피노자 (데카르트 동시대 철학자)** | 정신과 신체는 한 개체의 두 표현이라는 '평행론'을 주장. 정신은 특별하지 않으며, '정신적 자동기계'이다. 모든 것은 필연적이다. 인간의 행위에 대해 조소하거나 개탄, 비난하지 않고 이해하려 노력하며, 인간 감정들을 인간 본성의 악덕이 아닌 인간 본성에 속하는 성질로 이해한다 (예: 열, 냉기, 폭풍, 번개 등이 대기의 본성에 속하듯이). | | | **현대 혹은 미래: 인간과 기계의 공존** | 인간과 기계의 구별은 이성(계산)과 감정의 문제로 이어진다. 인공지능 로봇이 감정을 가질 수 있는지에 대한 질문과 함께, 기계가 갖는 감정이 아니라 우리가 기계에 대해 갖는 느낌으로 질문을 전환해야 한다고 제시된다 (자동기계, 고물수레, 소통하는 로봇 팔 등). | |

2. 플라톤 철학

| 주제 | 주요 내용 | 출처 | | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | | **플라톤 철학의 시대적 배경** | 소피스트는 '지혜를 가진 자'로, 잘 사는 방법인 웅변술을 중요시했다. 객관적 진리는 없다는 상대주의를 주장했고 , 인간은 자기 욕망을 최대한 허용하고 충족시킬 힘을 가져야 한다는 투명성을 비판했다. 펠로폰네소스 전쟁(BC 431-404) 시기이며 , 민주정일 때 소크라테스가 사형당했다(BC 399). | | | **플라톤의 생애** | BC 429(427)년 유력 정치가 집안 출생. 20살에 소크라테스를 만났고 , 28살(BC 399)에 소크라테스가 사형당했다. BC 385년에 아카데미아를 설립했다. 60세, 66세에 시실리의 시라쿠스에서 현실 정치에 참여했다. BC 347(80세)에 사망했다. | | | **서술 방식의 특징** | 대화, 논박술(elenchus), 아포리아, 산파술을 사용했다. | | | **『국가』의 구성 및 문제** | 『국가(Politeia)』는 Polis(도시국가)의 '정체(조직 혹은 통치 형태)'를 다룬다. 주요 내용은 전통적 정의 개념, 플라톤의 정의 개념, 이상 국가의 실현 가능성(철인 통치자 선발 및 교육), 정체의 쇠퇴, 철학과 시의 대립, 혼의 불멸과 정의에 대한 보상 등이다. 태양, 선분, 동굴의 비유가 나온다. | | | **주요 개념어: 정의(dike)** | 늘 처신하는 방식/습관 , 어떤 사람에 대해서 기대/예상하고 있는 것 , '남에게 받은 것을 갚는 것', '각자에게 각자의 것을' (dikaiosyne). 소크라테스는 "정의는 유익한 것"이라는 데에 전적으로 동의한다. | | | **주요 개념어: 덕(Arete)** | 탁월함은 일종의 정신적인 건강, 아름다움, 좋은 상태이지만, 악덕은 일종의 병, 수치스러운 상태, 허약함인 것 같다. Arete는 '기능(Ergon)'을 좋게 만드는 것과 관련된다. | | | **주요 개념어: 원인(aitia)** | 질료인(Materia), 형상인(forma), 작용인(Causa efficiens), 목적인(causa finalis). | | | **실재의 구분** | 가시적인(visible) 것(이미지, 그림자, 실물/개체들)과 가지적인(intelligible) 것(수학적 대상, 형상)으로 나눈다. 전자는 doxa(의견, 억견, 믿음), 후자는 noesis(앎)에 해당한다. 확실한 앎은 상기(recollection, anamnesis)를 통해 가능하다. | | | **철인 통치자** | 진리의 폭정이라는 비판을 받는다 (아렌트). 이상에 대한 열망과 동경은 현실에 대한 깊은 절망에서 나온다. | |

3. 칸트 철학

| 주제 | 주요 내용 | 출처 | | | | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- | --- | | **계몽** | '계몽'이란 우리가 마땅히 스스로 책임져야 할 미성년의 상태로부터 벗어나는 것이다. "감히 알려고 하라!"(Sapere aude). | | | | | **코페르니쿠스적 전회 (인식론)** | 칸트 이전의 인식론은 마음을 거울로 보는 수동적 모델이었다 (대상 -> 마음). 칸트 인식론은 마음이 능동적으로 대상에 작용하며, 마음이 현상에 개입한다 (마음 -> 현상 <- 사물 그 자체). 사물 그 자체(Ding an sich)는 알 수 없고, 우리가 아는 것은 현상뿐이다. | | | | | **초월적 vs 초월론적** | 초월적(transzendent)은 따지지 말아야 할 것, 초월론적(transzendental)은 우리의 내재적 능력 또는 경험을 가능하게 하는 근거를 의미한다. | | | | | **인식의 형식** | 감성, 상상, 지성, 이성으로 구성. 감성의 형식은 시간과 공간 , 지성의 형식은 양, 질, 관계, 양상 등이다. 내용(직관)이 없는 사고는 공허하고, 개념이 없는 직관은 맹목적이다. | | | | | **『순수이성비판』의 질문** | "나는 무엇을 알 수 있는가?"에 대한 답으로, 자아, 신, 우주와 같은 대상에 대해서는 대답할 수 없다. | | | | | **『실천이성비판』의 질문 (윤리학)** | "나는 무엇을 해야 하나?"에 대한 답을 찾는다. | | | | | **칸트 이전 윤리학** | 고대철학은 삶의 목표를 행복에 두었으며, 행복한 삶은 이성을 따르는 삶이라고 보았다. 공리주의(결과주의)는 최대다수의 최대행복을 추구했고 , 데이비드 흄은 공감(sympathy)을 중요시했다. | | | | | **칸트의 윤리학** | 오로지 '선의지'만이 절대적으로 선하며 (결과 X) , 행위의 준칙이 보편적 법칙/보편적 자연법칙이 되기를 동시에 의지할 수 있는 준칙에 따라서만 행위해야 한다. 또한, 다른 사람을 도구로서만이 아니라, 항상 목적으로도 대해야 한다. 문화적 배경이 다른 사람들이 이합집산하는 곳일수록 규칙을 적게 하는 것이 평화의 길이다 (최소의 법칙). | | | | | **『판단력비판』 (미학)** | **규정적 판단**은 보편적 개념에서 시작하여 특수한 사례로 나아가는 판단(예: 판사). **반성적 판단**은 우연적 사실로부터 새로운 보편자로 나아가는 판단(예: 예술가, 새로운 규칙 창조). 천재는 자기가 하는 일이 무엇인지 모르면서 새로운 규칙을 창조하는 자이다. **취미 판단**은 무관심한 만족감 , 목적 없는 합목적성 (조화로운 통일성, 의도 X) , 개념 없는 보편성 (타인의 동의 요구) 을 동반한다. **숭고**는 깎아지른 절벽, 광풍 속의 바다와 같이 상상력이 압도되어 총괄하는 이미지를 만들어내지 못하는 것(무능력, 상실 경험) 앞에서 느끼는 감정이다. 아름다움은 상상력과 지성이 자유롭게 일치하지만, 숭고는 무기력한 상상력에 이성의 개입이 더해진다. | | | |

4. 니체 철학

| 주제 | 주요 내용 | 출처 | | | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- | | **니체의 생애** | 1844년 독일 뢰켄 출생. 1869년 바젤 대학 교수 임용. 1872년 『비극의 탄생』 출간 (문헌학자들의 혹평과 비문헌학자들의 찬사). 1879년 건강 악화로 퇴직. 1889년 정신병원 입원 후 1900년 사망. 쇼펜하우어와 바그너와의 만남이 있었다. | | | | **니체와 소크라테스** | 니체에게 소크라테스는 악당이지만, 니체는 소크라테스의 변명의 모델에 입각해서 자신의 과제를 인식한다. | | | | **미래의 철학자들** | 미래의 철학자들은 독단주의자들이 아니며, "자신의 진리가 모든 사람을 위한 진리라고 가정하는 것"은 그들의 자부심이나 취향을 모독하는 것이다. 그들은 "나의 판단은 나 자신의 판단이다"라고 말할 것이다. | | | | **계보학과 원근법주의** | **계보학**은 기원에 대한 물음을 통해 정당화 대신 의심을 던진다. 기원을 찬양하는 것은 사물의 시초에 가장 값어치 있고 본질적인 것이 있었다고 생각하게 만든다. 계보학자는 사물의 배후에 영원하고 본질적인 비밀은 없으며, 본질이라는 것도 이질적인 것으로부터 엉성하게 조작된 결과라는 것을 발견한다. | | | | **원근법주의 (퍼스펙티비즘)** | '오류의 가치'를 통해 사물을 '대강' 보는 눈을 이야기하며, 개구리의 퍼스펙티브(가까이 낮게 있는 물체는 크게 보이고, 높이 멀리 있는 물체는 희미하게 보이며, 빨리 움직이는 것이 잘 포착됨)를 예시한다. 세상은 '해석이지, 텍스트가 아니다'. 객관적 이해란 지적인 오만함의 표현이며 , 모든 탐구 활동은 특정한 관점을 전제로 한다. 니체는 퍼스펙티비즘을 통해 얼마나 다양한 퍼스펙티브를 체험했는지 묻는다. "다양한 종류의 눈이 있다... 따라서 다양한 종류의 진리가 있고, 따라서 어떠한 진리도 없다"라고 말하며, 절대주의와 상대주의를 비판한다. | | | | **『도덕의 계보』** | '선과 악', '좋음과 나쁨'의 기원, '죄', '양심의 가책' 등, 금욕주의적 이상이 무엇을 의미하는지에 대해 다룬다. | | |

5. 벤야민, 기술복제와 예술작품

2주차: 동굴의 비유 (플라톤, 『국가』 제7권)

  • **주요 내용:** 플라톤의 '동굴의 비유'는 교육받은 본성과 교육받지 못한 본성의 차이를 비교하기 위한 상상으로 시작됩니다.
  • 사람들은 지하 동굴에 갇혀 다리와 목이 쇠사슬에 묶여 앞쪽 벽면(CD)만 볼 수 있습니다.
  • 그들 뒤편 위쪽 멀리서 불빛이 비추고, 불과 수감자들(AB) 사이에는 나지막한 담(GH)이 쌓인 길이 나 있습니다.
  • 사람들은 그 담을 따라 여러 도구, 입상, 동물 형상 등의 인공물을 운반하고 있습니다.
  • 수감자들은 불빛에 의해 맞은편 동굴 벽면에 투영된 그림자들 외에는 아무것도 볼 수 없으며, 이 그림자들이 실재라고 믿습니다.
  • **해방과 교육:** 쇠사슬에서 풀려나 불빛을 보게 강요받는다면, 그는 고통받고 눈이 부셔서 그림자의 실물들을 바라볼 수 없을 것입니다.
  • **진정한 교육:** 교육은 혼의 지적인 기관에 시력을 넣어주는 기술이 아니라, 이미 시력을 갖고 있지만 방향이 옳지 못한 기관을 실재(선의 이데아)를 향해 전향시키는 기술입니다.
  • **선의 이데아:** 지성에 의해 알 수 있는 세계에서 선의 이데아는 마지막으로, 노력을 해야만 겨우 볼 수 있으며 , 가시적인 세계에서는 빛과 빛의 주인을 낳고, 지성 세계에서는 진리와 지성을 창조하는 모든 올바른 것과 아름다운 것의 원인입니다.
  • **통치와 철학자:** 진정한 철학자(위쪽 세계를 관조한 사람)는 위쪽 세계에 머물고 싶어 하지만 , 국가의 건설자로서 그들이 다시 동굴로 내려가 수감자들의 고통과 명예에 참여하도록 강제해야 합니다.
  • 법의 관심사는 특정 계급의 행복이 아니라 국가 전체의 행복이며, 철학자들이 공무에 참여할 능력을 갖추도록 훌륭하고 완벽한 교육을 받은 것은 시민들을 위함입니다.
  • 통치하는 일에 가장 열의가 적은 나라가 가장 훌륭하고 조용하게 통치됩니다.

3주차: 성찰 (데카르트)

  • **제1 성찰: 의심할 수 있는 것들에 관하여**
  • 학문에 있어 확고하고 불변하는 것을 세우려면 일생에 한 번은 기존의 의견을 철저하게 전복해야 한다는 것을 깨달았습니다.
  • 의견들 각각에 의심할 만한 이유가 조금이라도 있다면 전체를 거부할 수 있으며, 기존 의견이 의존하는 **원리들 자체를 검토**합니다.
  • **감각의 의심:** 감각은 종종 우리를 속이므로 전적으로 신뢰하지 않는 것이 현명합니다.
  • **꿈의 가설:** 깨어 있다는 것과 꿈을 꾸고 있다는 것을 확실히 구별해 줄 어떤 징표도 없다는 사실에 놀라며, 개별적인 것(손, 몸통 등)의 실재성을 의심합니다.
  • **단순하고 보편적인 것의 의심:** 물질적 본성 일반, 연장, 형태, 크기, 수, 시간 등 더 단순하고 보편적인 것들은 참으로 현존한다고 인정해야 할 듯하나,
  • **전능한 악마 가설:** 모든 것을 할 수 있는 신이나 유능하고 교활한 악령이 나를 속이려 하고 있다고 가정하고, 하늘, 땅, 연장적 사물 등 모든 외적인 것을 꿈의 환상이라 가정합니다. 단순한 수학적 진리(2+3=5)까지도 신이나 악마에 의해 속임을 당하고 있는 것은 아닐까 의심합니다.
  • **제2 성찰: 인간 정신의 본성에 관하여 ; 정신이 물체보다 더 쉽게 인식된다는 것**
  • **코기토(Cogito)의 발견:** 모든 것을 의심하더라도, '내가 어떤 것을 설득했다면, 확실히 나는 있었을 것이다'. '그(기만자)가 나를 속인다면, 내가 있다는 것은 의심할 수 없다'.
  • "나는 있다. 나는 현존한다는 명제는 내가 이것을 발언할 때마다 혹은 마음속에 품을 때마다 **필연적으로 참**이다".
  • **나의 본성:** 나는 사유하는 동안만 존재하는, **사유하는 것(res cogitans)**, 즉 정신, 영혼, 지성, 이성이다. 사유하는 것은 의심하고, 이해하며, 긍정하고, 부정하며, 의욕하고, 의욕하지 않으며, 상상하고, 감각하는 것을 포함합니다.
  • **상상력과 감각:** 상상력과 감각하는 힘(작용) 자체는 내 안에 실재하며, 사유의 한 부분을 형성합니다. 상상하거나 감각된 것 자체는 거짓일 수 있지만, 그것을 상상하거나 감각하는 행위(사유)는 확실합니다.
  • **밀랍의 예와 정신의 우위:** 밀랍은 불 가까이서 맛, 향기, 빛깔, 모양, 크기 등 **감각적 성질이 모두 변하더라도** 여전히 동일한 밀랍으로 남아 있습니다.
  • 밀랍의 본성은 연장성, 유연성, 가변성뿐이며, 이는 감각이나 상상력으로 모두 포착할 수 없고 **오직 정신의 통찰(지성)**에 의해서만 지각됩니다.
  • 물체를 인식할 수 있도록 해 주는 모든 근거들은 동시에 내 정신의 본성을 더 잘 알게 해 주며 , 결국 **내 정신보다 더 쉽게 또 더 명증적으로 인식되는 것은 아무것도 없음**을 알게 됩니다.

5주차-1: 『순수이성비판』 서론 (칸트)

  • **경험적 인식과 선험적 인식의 구별:**
  • 우리의 모든 인식은 **경험과 함께 시작**되지만, 모든 인식이 경험으로부터 생겨나는 것은 아닙니다.
  • **선험적 인식**은 경험으로부터 그리고 모든 감각 인상들로부터도 독립적으로 생긴 인식을 의미합니다.
  • **순수한 인식**은 선험적 인식들 가운데 전혀 아무런 경험적인 것도 섞여 있지 않은 인식입니다. (예: '모든 변화는 그 원인을 갖는다'는 선험적이지만 '변화' 개념이 경험에서 오므로 순수하지는 않다.)
  • **분석 판단과 종합 판단의 구별:**
  • **분석 판단(설명 판단):** 술어 개념(B)이 주어 개념(A)에 (암암리에) 포함되어 있는 판단입니다. 주어 개념을 분해하여 그 안에 이미 생각되어 있던 것을 해명하는 것일 뿐, 개념을 확장하지 않습니다. (예: '모든 물체는 연장적이다' )
  • **종합 판단(확장 판단):** 술어 개념(B)이 주어 개념(A)의 밖에 놓여 있지만 연결되어 있는 판단입니다. 주어 개념에 그 안에서는 전혀 생각할 수 없었던 술어를 덧붙여 인식을 확장합니다. (예: '모든 물체는 무겁다' )
  • **경험 판단**은 그 자체로 모두 **종합적**입니다.
  • **선험적 종합 판단의 문제:** 개념 A를 넘어 개념 B를 결합된 것으로 인식하기 위해 의지할 알려지지 않은 것(X)은 무엇인가?. 우리의 선험적 인식의 궁극 의도는 이러한 확장 원칙들에 근거합니다.
  • **선험적 종합 판단의 포함:** 이성의 모든 이론적 학문들에는 선험적 종합 판단들이 원리로서 포함되어 있습니다.
  • **수학:** 수학의 판단들은 모두 **종합적**입니다. (예: '7+5=12' , '직선은 두 점 사이의 가장 짧은 선이다' )
  • **자연과학:** 자연과학은 원리로서 선험적 종합 판단을 자기 안에 포함하고 있습니다. (예: '물체 세계의 모든 변화에서 물질의 양은 불변이다' )
  • **형이상학:** 형이상학은 선험적 종합 인식들을 포함해야 하며, 그 목적상 순전한 **선험적 종합 명제들**로 이루어져 있습니다.

5주차-2: 『윤리형이상학 정초』 (칸트)

  • **선의지(善意志, Good Will):**
  • 이 세계에서 또는 이 세계 밖에서까지라도 아무런 제한 없이 선하다고 생각될 수 있을 것은 **오로지 선의지뿐**입니다.
  • 지성, 용기, 권력, 행복 같은 다른 자질들은 선의지가 없을 때 악하고 해가 될 수도 있습니다.
  • 선의지는 성취한 것이나 목적 달성에 쓸모 있음으로 말미암아 선한 것이 아니라, **오로지 그 의욕함으로 말미암아, 그 자체로 선한 것**입니다.
  • 선의지는 행복을 누릴 품격(자격) 있음의 필요불가결한 조건입니다.
  • 이성의 참다운 사명은 그 자체로서 **선한 의지를 낳는 것**이어야만 합니다.
  • **의무와 도덕적 가치:**
  • 선의지의 개념을 발전시키기 위해 **의무 개념**을 취합니다.
  • **의무로부터의 행위**는 행위를 통해 달성해야 할 **의도에서** 도덕적 가치를 갖는 것이 아니라, 그 행위가 결의되는 **준칙에서** 가치를 갖습니다.
  • 도덕적 가치는 행위의 결과나 목적과 무관하게, **순전히 의욕의 원리**에 의존합니다.
  • **셋째 명제:** 의무는 **법칙에 대한 존경**으로부터 말미암은 행위의 필연성입니다. 존경의 대상은 경향성이 아니라 **순전한 법칙 그 자체**입니다.
  • **정언 명령 (윤리성의 명령):**
  • 모든 명령은 **가언적**이거나 **정언적**으로 지시명령합니다.
  • **가언 명령 (기술적 규칙/실용적 충고):** 어떤 다른 목적에 도달하기 위한 **수단**으로서 행위의 필연성을 표상합니다. (예: 영리하라 )
  • **정언 명령 (도덕적 법칙):** 한 행위를 그 **자체로서**, 어떤 다른 목적과 관계없이, **객관적으로 필연적인 것으로** 표상합니다.
  • 정언 명령은 어떤 조건에도 제한을 받지 않으며, **절대적으로 필연적**이고, 본래적으로 지시명령이라고 일컬을 수 있습니다.
  • **정언 명령의 유일한 정식:** "그 준칙이 보편적 법칙이 될 것을, 그 준칙을 통해 네가 동시에 의욕할 수 있는, **오직 그런 준칙에 따라서만 행위하라**".
  • **인간(성)을 목적으로 대하라 (목적 정식):**
  • 인간은, 그리고 일반적으로 모든 이성적 존재자는, **목적 그 자체로 실존**하며, 한낱 임의적 사용을 위한 **수단으로서 실존하는 것이 아닙니다**.
  • 인간은 항상 동시에 목적으로서 보아야 합니다. 이성적 존재자는 인격이라 불리며, 객관적인 목적들입니다.
  • **실천 명령:** "네가 너 자신의 인격에서나 다른 모든 사람의 인격에서 인간(성)을 항상 **동시에 목적으로 대하고, 결코 한낱 수단으로 대하지 않도록, 그렇게 행위하라**".

6주차-1: 『도덕의 계보』 제1논문 (니체)

  • **가치 평가의 기원 (귀족적 가치 평가):**
  • '좋음'이라는 판단은 '좋은 것'을 받았다고 표명하는 **이익을 얻는 사람들의 입장에서 나오는 것이 아닙니다**. (영국 심리학자의 주장 부정)
  • '좋음'은 저급한 모든 사람에 대비해서, **자기 자신과 자신의 행위를 좋다고 느끼는 고귀한 사람, 강한 사람**들에게 있었습니다.
  • 이들은 **거리의 파토스(Pathos der Distanz)**에서 가치를 창조하고 이름 새길 권리를 가졌습니다.
  • **좋음과 나쁨의 대립:** 고귀함과 거리의 파토스, 좀더 높은 지배 종족이 좀더 하위 종족에게 가지고 있는 지속적이고 지배적인 전체 감정 이것이 **'좋음'과 '나쁨'이라는 대립의 기원**입니다.
  • 귀족적 가치 판단은 **자기 자신을 의기양양하게 긍정하는 것**에서 생겨납니다.
  • **노예 도덕 (원한의 도덕):**
  • 성직자 민족인 **유대인**은 자신의 적과 압제자에게 **가치를 철저하게 전도시킴**으로써 복수를 했습니다.
  • **도덕에서의 노예 반란**은 **원한(ressentiment)** 자체가 창조적이 되고 가치를 낳게 될 때 시작됩니다.
  • **노예 도덕**은 처음부터 **'밖에 있는 것', '다른 것', '자기가 아닌 것'을 부정**하는 것에서 생겨납니다.
  • 원한을 지닌 인간은 '나쁜 적', **'악한 사람'을 생각해 내고**, 그것의 잔상 또는 대립물로 '선한 인간' (자기 자신)을 생각해 냅니다.
  • 노예 도덕은 외부의 자극이 필요한 **반작용**입니다.

6주차-2: 『도덕의 계보』 제2논문 (니체)

  • **약속할 수 있는 동물:**
  • **약속할 수 있는 동물을 기르는 것**이야말로 자연이 인간에게 부여한 역설적인 과제입니다.
  • 인간은 미래를 미리 정하기 위해 필연적 사건과 우연적 사건을 구별하고, 인과적으로 사고하며, 미래의 일을 현재의 일처럼 예견할 수 있는 방법을 배워야 합니다.
  • 결국 인간은 스스로 예측가능하고, 규칙적이며, 필연적인 존재가 되어야 합니다.
  • **주권적 개인:** 풍습의 도덕과 사회적 강제에 힘입어 인간은 예측가능하게 되었고, 이 과정의 가장 잘 익은 과실은 **주권적 개인**입니다. 그는 자기 자신의 독립적인 의지, 약속할 수 있는 권리를 가진 인간입니다.
  • 이 주권적 인간은 자신의 책임에 대한 자랑스러운 의식, 자유와 힘에 대한 의식을 **양심**이라고 부릅니다.
  • 기억에 남기기 위해서는 **끊임없이 고통을 주는 것**이 필요했습니다.
  • **죄와 부채의 기원:**
  • 도덕의 주요 개념인 **'죄(Schuld)'는 '부채(Schulden)'라는 극히 물질적인 개념에서 유래**되었습니다.
  • 손해와 고통은 등가라는 관념은 **채권자와 채무자 사이의 계약 관계**에서 힘을 얻었습니다.
  • 채무자는 상환하지 못할 경우 자신의 육체, 아내, 자유, 생명 등을 저당잡힙니다.
  • 채권자는 채무자에게 '형벌'을 가함으로써 자신의 권력을 발휘하는 **쾌감(잔인함)**을 누릴 권한을 얻습니다.
  • '죄', '양심', '의무', '의무의 신성함' 등과 같은 도덕적 개념 세계의 발생지는 이 영역, 즉 **채무법**입니다.
  • **양심의 가책 (내면화):**
  • **양심의 가책**은 인간이 사회와 평화의 구속에 갇혔을 때 빠져들 수밖에 없었던 심각한 병입니다.
  • **밖으로 발산되지 않는 모든 본능**은 **안으로 향하게 되며**, 이것이 인간의 **내면화**입니다.
  • 이것으로 인해 후에 **'영혼'**이라고 불리는 것이 자라납니다.
  • 적의 잔인함이나 파괴에 대한 쾌감 같은 거칠고 자유로운 본능이 스스로에게 방향을 돌리는 것, 이것이 **'양심의 가책'의 기원**입니다.
  • 자기가 없는 자, 자기 자신을 희생하는 자가 느끼는 쾌감은 **잔인함**이며 , **양심의 가책**이야말로 비이기적인 것의 가치를 낳는 전제가 됩니다.

6주차-3: 『도덕의 계보』 제3논문 (니체)

  • **금욕주의적 이상의 의미:**
  • 금욕주의적 이상은 **인간 의지가 지닌 공허의 공포**를 표현하며, **인간의 의지는 하나의 목표가 필요**하다는 사실을 의미합니다.
  • 인간은 아무것도 의욕하지 않는 것보다, 오히려 **허무를 의욕**하는 것입니다.
  • 금욕주의적 이상이 없었다면 인간의 생존은 아무 목표도 없고, "도대체 인간이란 무엇 때문에 존재하는가?"는 해답 없는 물음이었을 것입니다.
  • **고통의 무의미:**
  • 인간의 문제는 고통 자체가 아니라, **"무엇 때문에 고통스러워하는가?"라는 물음의 외침에 대한 해답이 없다는 것**이었습니다.
  • 고통의 의미나 목적이 밝혀진다면 인간은 고통을 바라고 찾기도 합니다.
  • **금욕주의적 이상은 인류에 하나의 의미를 주었습니다**.
  • 이 이상 속에서 고통은 해석되었고, 모든 고통을 **죄라는 관점 아래**로 가져갔습니다.
  • **금욕주의적 이상에 대한 평가:**
  • 이 이상은 인간적인 것, 동물적인 것, 물질적인 것, 관능, 행복, 미에 대한 **증오와 혐오**를 의미하며 , **허무를 향한 의지**이며, **삶에 대한 적의**이며, 삶의 가장 근본적인 전제들에 대항한 반발을 의미합니다.
  • 이 이상은 **퇴화되어가는 삶의 방어 본능과 구원 본능**에서 생겨난 것으로, 삶을 보존하기 위한 기교입니다.
  • 철학자가 금욕주의적 이상을 신봉한다면, 이는 그 철학자가 **고통에서 벗어나려고 한다**는 것을 의미합니다.
  • 금욕주의적 이상은 모든 철학을 지배해 왔기 때문에, 진리를 문제 삼는 것이 허용되지 않았습니다. 금욕주의적 이상의 신앙이 부정되는 순간, **진리의 가치에 대한 문제**가 있게 됩니다.
  • **관점주의적 인식 (객관성의 부정):**
  • **객관성이란 '무관심한 직관'으로 이해해서는 안 되며**, 오히려 지성의 찬반을 제어하고, **인식을 위해 관점과 정서적 해석의 차이를 이용할 줄 아는 능력**으로 이해해야 합니다.
  • '순수하고 의지가 없고 고통이 없고 무시간적인 인식의 주관'이라는 낡은 개념의 허구를 경계해야 합니다.
  • **오직 관점주의적 '인식'만이 존재**합니다. 한 사태에 대해 더 많은 정서나 다양한 눈을 맞출수록, 그 사태에 대한 우리의 '개념'이나 '객관성'은 더욱 완벽해질 것입니다.

7주차: 기술복제시대의 예술작품 (발터 벤야민)

  • **예술작품의 기술적 복제:**
  • 예술작품은 원칙적으로 항상 복제가 가능했지만, **기술적 복제는 새로운 현상**입니다.
  • 목판 등장 이후 그래픽, 인쇄를 통한 문자 복제, 19세기 초 석판인쇄술을 통한 그래픽 대량 복제, **사진술**을 통한 영상 복제가 이루어졌습니다.
  • 사진술은 영상 복제 과정에서 손의 가장 중요한 예술적 임무를 벗어나게 했고, **렌즈를 투시하는 눈**이 이를 담당하게 했습니다.
  • 1900년 전후 기술적 복제는 전승된 예술작품 전체를 대상으로 만들고 독자적인 자리를 점유하는 수준에 도달했습니다.
  • **아우라(Aura)의 붕괴:**
  • 가장 완벽한 복제에서도 예술작품의 **'여기 와 지금' (일회적인 현존재)**은 빠져 있습니다.
  • 원작이 지금 여기에 존재한다는 사실이 원작의 **진품성**이라는 개념의 내용을 이룹니다. 진품성은 기술적 복제의 가능성에서 벗어나 있습니다.
  • 기술적 복제는 원작의 모사를 원작이 도달할 수 없는 상황(수용자의 요구)에 가져다놓을 수 있습니다.
  • 이러한 상황은 예술작품의 **여기 와 지금의 가치를 하락**시킵니다. 이 과정에서 예술의 대상에서 가장 민감한 핵심 부분인 **진품성**이 건드려집니다.
  • **아우라의 정의:** 자연적 대상의 아우라를 **"아무리 가까이 있더라도 멀리 떨어져 있는 어떤 것의 일회적인 현상"이라고 정의할 수 있습니다.**
  • 기술적 복제 가능성의 시대에서 위축되고 있는 것은 예술작품의 **아우라**입니다.
  • 복제기술은 복제된 것을 전통의 영역에서 떼어내고, 복제를 대량화하며, 수용자가 쉽게 접하게 함으로써 **현재화**합니다. 이 두 과정은 **전통을 엄청나게 뒤흔듭니다**.
  • **제의가치와 전시가치:**
  • 예술작품의 수용은 **제의가치(Kultwert)**와 **전시가치(Ausstellungswert)**라는 두 가지 대립되는 역점을 두고 이루어집니다.
  • 예술작품이 전통의 맥락에 편입되는 **원초적 방식은 제의(祭儀, Kult)**에서 표현되었습니다. 가장 오래된 예술작품들은 의식(儀式)에 쓰이기 위해 생겨났습니다.
  • 예술작품의 기술적 복제 가능성은 세계 역사상 처음으로 예술작품이 지금까지 종교적 의식 속에서 살아온 기생적 삶의 방식에서 벗어나도록 하였습니다.
  • 예술이 제의에 바탕을 두었었는데, 이제 예술은 다른 실천, 즉 **정치에 바탕**을 두게 됩니다.
  • 기술적 복제 방법이 생겨나면서 전시 가능성이 엄청나게 커졌고, 예술작품이 갖는 본성의 질적 변화가 일어났습니다.
  • 오늘날에는 절대적 역점이 **전시가치**에 주어짐으로써 예술작품은 전혀 새로운 기능을 지닌 형상물이 되었습니다.
  • **사진과 영화:**
  • **사진**에서는 전시가치가 제의가치를 전면적으로 밀어내기 시작하며 , 제의가치는 인간의 얼굴에서 최후의 보루를 찾습니다.
  • **영화**배우의 연기는 카메라를 통하여 제시됩니다. 카메라는 연기를 통일적인 전체로 간주하지 않고 여러 각도에서 촬영하며, **몽타주**로 완성됩니다.
  • 영화배우는 자신의 연기를 관중에게 직접 보여주지 못하므로, 공연 도중 관중에 맞추어 연기를 조정하는 가능성을 상실합니다. 관중은 테스트하는 감식자의 태도를 취합니다.
  • 영화배우는 카메라 앞에서 연기하며, **자신의 생생한 인격 전부를 바치면서도 그 인격의 아우라는 포기**한 채 연기하지 않으면 안 됩니다.
  • 카메라맨은 외과의사와 같이 대상의 조직에 깊숙이 침투하며, 그의 영상은 여러 개로 쪼개져 있는 **단편적 영상들**입니다.
  • 영화는 **시각적 무의식(das Optisch-Unbewußte)**의 세계를 알게 해 줍니다.
  • 영화의 충격효과는 **정신분산(오락)**에 잘 부응합니다. 정신이 산만한 대중은 예술작품이 자신들 속으로 빠져 들어오게 합니다. 관중은 정신이 산만한 시험관입니다.
  • **예술의 정치화:**
  • 파시즘은 무산계급화한 대중을 소유관계는 건드리지 않은 채 조직하려 하며, 대중에게 **표현을 제공**하려고 합니다. 이것은 **정치적 삶의 심미화(審美化)**로 치닫게 됩니다.
  • 전쟁만이 전승된 소유관계를 그대로 유지하면서 현재의 모든 기술 수단을 동원할 수 있게 합니다.
  • 파시즘은 전쟁의 파괴성을 '예술적 만족'으로 기대하는 **예술지상주의의 마지막 완성**입니다.
  • **공산주의는 예술의 정치화로써 파시즘에 맞서고 있습니다**
