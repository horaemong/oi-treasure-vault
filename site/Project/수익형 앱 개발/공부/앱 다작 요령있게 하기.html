주의

하나의 앱을 너무 동일하게 만들지 말 것

  • 최소한 다른 앱 처럼 보여야한다.
  • 동일한 ui복사 붙혀넣기 X

이론

서버 UI Driven 구조

필요성

  • 하나의 Client 프로젝트만 필요
  • DB에 데이터만 넣어주면 UI 변경
  • DB에 데이터만 넣어주면 콘텐츠 변경

즉 앱 개발 속도 폭발적 상승

1개의 서버에 여러개의 앱을 연결

아마존 aws의 무료 플랜 ec2가 앱 200개 까지 버텨줌 : t2.micro

단점 위험 분산 불가

해결법

  1. 처음 설계 잘하기
  2. 많은 처리가 필요한 부분 캐싱처리
  3. 무거운 로직은 가볍게 리팩토링
  4. 테스트 코드 작성 꼼곰히
  5. 외부 API 호출 부분은 모니터링 철저히 대비
  6. 트래픽 대비 미리하기
  7. 오토스케일링 설정

네이버 카페는 카페 하나하나가 앱이 될 수 있다.

각 메뉴 하나를 기능으로 만든다면?
