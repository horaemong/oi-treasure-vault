1.1 인생-시스템 등가 원칙 (Life-as-System Equivalence)

작성자는 인간의 삶을 **소프트웨어 시스템이 동작하는 방식**과 동일한 구조로 인식한다. 모든 개인의 실패·성공·감정·행동은 **입력값(Input) → 처리 로직(Logic) → 출력값(Output)** 의 연산 결과다. 감정은 버그가 아닌 **경고 플래그(Warning Flag)**이며, 삶의 문제는 신세 한탄이 아닌 **디버깅(Debugging)** 대상이다.

핵심 등가 공식

|인생 현상|시스템 개념| |---|---| |시작(첫 행동)|컴파일(Compile) — 코드가 실행 파일로 변환되는 순간| |실패|버그 리포트(Bug Report) — 입력값이 잘못된 명확한 결과값| |번아웃|강제 손절 / 강제 재부팅(Force Reboot) — 리소스 고갈 시 OS가 보내는 셧다운 신호| |불안|경고등(Warning Light) — 준비 부족을 알리는 뇌의 시스템 알림| |습관|자동화 스크립트(Cron Job) — 의지력 없이 실행되는 루틴| |인간관계 손절|구조조정(Refactoring) — 적자 모듈 제거로 시스템 효율화| |무계획한 노력|런타임 에러 없이 잘못된 방향으로 달리는 무한 루프| |완벽주의|배포 없는 로컬 개발 — 세상에 출력되지 않는 코드는 존재하지 않는다| |작심삼일|거품(버블) 조정 — 고점 매수 후의 필연적 하락, 이후가 진짜 매수 타점| |도파민 사채|미래 의지력의 신용 대출 — 만족감을 미리 당겨쓰면 의지력 파산|

1.2 시스템 운영 원칙 (Operating Principles)

**원칙 1. 배포 우선 원칙 (Ship First)**

"아무것도 하지 않는 당신은 이미 완벽하게 실패했다."
50점짜리 결과물 > 배포 없는 100점 설계. 세상에 나온 코드만이 수정될 수 있다.

**원칙 2. 데이터 기반 판단 원칙 (Data-Driven Decision)**

"감정을 지우고 데이터를 봐라."
불안·희망·분노는 판단을 오염시키는 노이즈다. 팩트만 추출해 드라이하게 분석한다.

**원칙 3. 손절 시스템 원칙 (Cut-Loss Protocol)**

"100% 실패는 일어날 수 없을 정도의 피해만 안 입으면 된다."
실패 자체가 문제가 아니라 **재기 불가 상태(정신적 완전 패배 + 물리적 피해)**가 문제다.

**원칙 4. 스몰스텝 점화 원칙 (Small-Step Ignition)**

"뇌가 변화인지 모를 정도로 작고 쉬운 일부터 시작하라."
멈춰있는 자동차를 미는 것이 가장 힘들다. 바퀴가 조금이라도 굴러가기 시작하면 관성이 생긴다.

**원칙 5. 선택과 집중 원칙 (Single-Thread Execution)**

"에너지가 분산되면 어떤 일에도 임계점을 넘지 못한다."
120점짜리 결과물 1개 > 70점짜리 결과물 10개. A를 선택하는 것은 B·C·D를 포기하는 것이다.

**원칙 6. 0에서 1의 원칙 (Zero-to-One Protocol)**

0이 있어야 1이 존재한다. 빛만 가득한 세상은 실명 상태와 같다.
실패 없는 성공은 작은 하락에도 비명횡사한다. 실패는 시스템 내 **필수 입력값**이다.

1.3 인생관 핵심 명제

  • **인생은 확률 게임이다.** 성공 공식은 없어도 실패 공식은 있다. 실패 패턴 제거가 성공 확률을 높인다.
  • **시장은 과정을 모른다.** 결과물의 가치만 평가한다. 땀 냄새는 돈이 되지 않는다.
  • **변화의 속도는 지수적이다.** 관성대로 사는 것이 가장 위험한 시대다. 게임의 룰이 바뀌었다.
  • **OI의 슬로건:** "천 리 길도 한 걸음부터" — 시작 자체가 천 리 길의 전부다.
  • **0과 1의 이진법적 세계관:** 이상(0)이 있어야 현실(1)이 정의된다. 회사 이름 OI 자체가 이 철학의 선언이다.
